# 인증과 인가

- 인증: 401 Unauthorized: 로그인이 안됐을 때
- 인가: 403 Forbidden: 남의 댓글 지우려고 할 때 

- 인증: 너 누구야?
- 인가: (누군지는 앎) 너 이거 못해 

# 댓글 삭제 시나리오
- 로그인
- 댓글 쓰기
- 댓글 삭제
- 로그아웃

1. mirim으로 로그인한 후에 댓글을 쓴다. 
2. 다른 계정으로 로그인해서 그 댓글을 지운다. (403)
3. 로그아웃을 해서 그 댓글을 지운다. (401)
4. mirim으로 로그인해서 그 댓글을 지운다. (204)

# N + 1 문제 
쿼리문 한 번으로 조회할 수 있는데 연관 관계의 수 만큼 쿼리가 n번 늘어나는 문제 

```json
{
    "loginId": "helloworld",
    "password": "hellowlrd",
    "name": "hellowlrd"
}
```
```json
{
    "loginId": "mirim",
    "password": "mirimmirim",
    "name": "mirim"
}
```
