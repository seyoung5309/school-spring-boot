# 프로필 (profile)
- 개발: dev (development)
- 운영: pro (production) - 실제 사용자가 쓰는 서비스
- 스프링 부트는 설정 파일을 환경별로 나눌 수 있음

## 규칙
- applicaion.yml: 공통, 항상 읽는다. 
- application-dev.yml: dev 프로필일 때만 추가로 읽는다. 
- application-prod.yml: prod 프로필일 때만 추가로 읽는다. 
- application-{프로필 이름}.yml

## 프로필 사용하는 방법
- application.yml: spring.profiles.active에 필요한 프로필 입력
- 설정 파일은 규칙대로 만들면 됨
- aspect는 @Profile 어노테이션으로 필요한 프로필 지정

## 자동 설정 조건 추가
- as-is: 라이브러리가 있거나 / 내가 안 만들었거나 / 설정이 켜져 있거나
- to-be: "@Profile 어노테이션으로 프로필 지정했거나" 추가 

# 운영 서버에 배포할 때마다 application.yml을 고치기 귀찮다. 
그래서 보통 실행할 때 프로필 옵션을 줘서, 운영 서버에서는 항상 prod 프로필로 실행하게 한다. 
java -jar build/libs/board-0.0.1-SNAPSHOT.jar -spring.profiles.active=prod

- applicaion.yml에 프로필을 뭘로 해놨든 실행할 때 지정하는 프로필이 우선이다.
