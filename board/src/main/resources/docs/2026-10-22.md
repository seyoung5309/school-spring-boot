# 외래키와 1:N 관계 

## 회원과 게시글
- 회원 1명이 게시글을 여러 개 쓸 수 있는가? 예.
  - 게시글 1개의 작성자가 여러 명일 수 있나요? 아니오. 
  => 1:N 관계, 1:N 관계에서 외래키는 N쪽에 붙는다. (게시글)
  - 게시글 테이블에 authorId

- 게시글과 댓글 
  - 1:N
  - N: 댓글
  - 댓글 테이블에 postId

- 회원과 댓글
  - 1:N
  - N: 댓글
  - 댓글 테이블에 authorId
