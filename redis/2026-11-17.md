Sorted Set
이유: point순으로 DESC 정렬을 해야 하며 사용자는 한 명만 있을 수 있기에 선택했다.
다른 걸 쓰면 뭐가 안 되나: Sorted Set이라면 별다른 작업 없이 원하는 값을 반환하지만, 나머지는 서버 처리가 필요하다.

1일
